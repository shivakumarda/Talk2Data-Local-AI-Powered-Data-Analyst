# ⚡ Talk2Data: Local AI-Powered Data Analyst

Talk2Data is a Streamlit web application that converts natural language queries into Pandas code to analyze CSV or Excel datasets automatically using a local **Llama 3.2** LLM.

## 🌟 Features
- 📂 Upload any CSV or Excel file with automatic column and type detection.
- 💬 Ask data queries in natural English or Hinglish.
- ⚡ Live execution of generated Pandas code for totals, aggregations, and top-N rankings.
- 📈 Visual chart support for quick insights.

## 🛠️ Tech Stack
- **Frontend / UI:** Streamlit
- **LLM Integration:** Ollama, LangChain (`llama3.2`)
- **Data Processing:** Pandas, Matplotlib, Seaborn
